# Downloadable release gate

The source repository is authorized for publication. A packaged download is not yet authorized.

Before publishing a packaged release: verify exact model redistribution terms and preserve teacher/dataset notices; use an applicable Microsoft C++ redistributable route rather than uploading privately copied system DLLs; match release assets to tested source; document meaning failures and actual language coverage; obtain Ruth's separate release approval. Never commit weights, binaries, personal logs, credentials or institutional details to this repository.
